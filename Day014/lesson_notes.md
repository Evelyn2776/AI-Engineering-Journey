# Strings
Text data wrapped inside quotes (e.g., "Hello").

# String indexing
Accessing a single character by its position number, starting at 0 (e.g., text[0] is the first letter, text[-1] is the last).

# String slicing
Extracting a specific section of a string using a range of indices, formatted as text[start:end].

# upper()
A method that converts every letter in the string to uppercase.

# lower()
A method that converts every letter in the string to lowercase.

# strip()
A method that deletes all accidental whitespaces from the very beginning and very end of a string.

# replace()
A method that finds a specific piece of text and swaps it with new text.

# split()
A method that cuts a string into pieces at a specified separator and puts them into a list.

# join()
A method that glues a list of multiple strings together into one single string using a separator.

# Searching strings
Using the in keyword to check if a specific word or letter exists inside a string, returning True or False.

# String cleaning
String cleaning more commonly involves things like:
removing unwanted whitespace
normalizing capitalization
standardizing formats
handling unwanted characters
normalizing text according to application requirements
# Strings in AI/NLP
The foundational step in Natural Language Processing where raw text is normalized (lowercased, stripped, and split) so AI models can understand matching concepts without getting confused by formatting.

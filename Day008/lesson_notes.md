# Lists
Lists are variables that contains more than one object and are mutable, indexed, ordered and allows duplicates.

# Indexes
Indexes are the number allocated to the objects in a list when you want to deal with a particular item in the list.

# Negative indexes
Negative indexes carries a negative sign (-) and it count from the end of the list.

# append()
'append()' adds an object to the list.

# remove()
'remove()' removes an object from the list.

# len()
'len()' tells the length of the list.

# Looping through lists
Allows you to run through each object in a list individually.

# Mutable objects
Mutable objects are objects which allows you to change the content of the object.

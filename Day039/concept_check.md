# Day 039 - Concept Check

1. What is logging?
Logging is the process of recording events that happen inside a program.

2. Which Python module provides logging?
The `logging` module.

3. What does `logging.basicConfig()` do?
It configures the basic logging system.

4. What is the DEBUG level?
DEBUG provides detailed information useful for debugging.

5. What is the INFO level?
INFO records normal application events.

6. What is the WARNING level?
WARNING indicates something unexpected or potentially problematic.

7. What is the ERROR level?
ERROR indicates that something failed.

8. What is the CRITICAL level?
CRITICAL indicates a serious failure.

9. What does `logging.exception()` do?
It logs an exception and its traceback, usually inside an `except` block.

10. Why is logging useful in AI engineering?
It helps monitor and debug models, APIs, agents, RAG systems, tools, and production applications.

### Key Takeaway
Logging → tracking events → debugging → monitoring → reliable applications

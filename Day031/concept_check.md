# Day 031 - Concept Check

1. **What is Regex?**
   A pattern system for working with text.

2. **What does `findall()` do?**
   Finds all matches.

3. **What does `search()` do?**
   Finds the first match.

4. **What does `sub()` do?**
   Replaces matches.

5. **What does `\d+` mean?**
   One or more digits.

6. **What do `^` and `$` mean?**
   Beginning and end of a string.

7. **What are `()` used for?**
   Capturing groups.

8. **Why is Regex useful in AI engineering?**
   For text processing, cleaning, validation, and extracting information.

### Key Takeaway

```text
findall → all matches
search  → first match
sub     → replace
group   → extract
```

# Lesson Notes - Day 002

## What is Programming?
It is the process of giving a computer clear, step-by-step instructions to perform a task or solve problems. Computers cannot guess, they only follow the instructions given to them.

## What is Python?
Python is a high-level language (human readable language), created by Guido van Rossum in 1991. It is easy to read and write and is a powerful language.

## What is the Python Interpreter?
Programming languages allow humans to write instructions in a readable way. The Python interpreter then translates those instructions into machine instructions that the CPU can execute.
## How Python Runs Code
1. I write python code.              
2. I save it as a '.py' file.       
3. The python interpreter reads the files.      
4. It translates the instructions.      
5. The Computer Hardware (CPU) executes them.       
6. The output appears.

# Boolean values
Boolean values are True and False only

# Comparison operators
Comparison operators are used to compare one object to another, suc as:
Greater than and equal (>=)
Equal to (==)
Less than (<)

# if
Used to make a decision and execute the statement if the condition is met.

# else
The else statement executes when none of the previous conditions are true.

# elif
The elif statement allows you to check additional conditions after an if statement.

# Indentation
Identation is spacing in a line of code and used to show that the line of code is under the above function or block od code.

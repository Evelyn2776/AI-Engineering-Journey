# What real-life task is similar to using a function? Explain why.
A function takes an input, runs a rule, and gives an output. A vending machine does the exact same thing every single time.
The Input: You type "A1" and put in two dollars. This is your input data.
The Rule: The machine checks the code and the money. It matches your input to the right product.
The Output: The machine drops out a bag of chips. This is your returned result.

# Why They Match
Predictable Results: If you put in the same money and pick the same code, you always get the same snack. A good function always gives the same output for the same input.
Hidden Steps: You do not need to know how the inside motors work. You only care about the input and the output.
No Side Effects: Buying a bag of chips does not change the lights on the front of the building or turn off the power. It just does one specific task.

# input()
This python built-in keyword is used to recieve input (values or objects) from the user.

# Strings from user input
Everytime a user gives an input that input is read as a string by python. That's because python treats keyboard input as text (strings) by default. The programmer decides whether that text should remain a string or be converted into another data type.

# Type conversion
Type conversion is important in python because without type conversion every input will be read as a string. It is also used to change one data type to another data type.

# Interactive programs
Interactive programs are programs that allows user to communicate with the program by allowing user to give input or feedback using the 'input()' keyword.

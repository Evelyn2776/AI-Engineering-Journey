# What is a string?
A sequence of text characters inside quotes.

# How does string indexing work?
Accessing a single character using its position number.

# What does text[0] mean?
The very first character of a string.

# What does text[-1] mean?
The very last character of a string.

# What is string slicing?
Extracting a specific section of text using [start:end].

# What does .upper() do?
Converts all letters in the text to uppercase.

# What does .lower() do?
Converts all letters in the text to lowercase.

# Why is .strip() useful?
Removes accidental spaces from the start and end.

# What does .replace() do?
Swaps old text with new text inside a string.

# What does .split() return?
Breaks text apart and returns a list of pieces.

# What does .join() do?
Glues a list of strings together into one text.

# What does in do with strings?
The in operator checks whether a value exists within another object, including strings and lists.

# Why is string cleaning important in AI?
Removes messy formatting or typos so data is uniform.

# Why might "AI" and "ai" need to be treated the same?
Computers see "AI" and "ai" as different data. Lowercasing ensures the AI recognizes them as the same concept.

# How could string processing be used before sending text to an AI model?
Normalize only what the application actually needs normalized before sending text to an AI model to guarantee accurate answers.

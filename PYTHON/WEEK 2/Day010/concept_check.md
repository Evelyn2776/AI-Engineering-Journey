# What is a tuple?
A tuple is a collection of data that is immutable, indexable, ordered and allows duplicates.

# How is a tuple different from a list?
A tuple and a list does the same thing, they are both collections of data, but tuples are unmutable (cannot chage once created).

# What is a set?
A set is a collection of data that is mutable, unordered, unindexable and doesn't allow duplicates.

# Why do sets remove duplicates?
Sets remove duplicates because they are designed to implement the mathematical concept of a set, which only cares about whether an item exists, not how many times it appears.

# What does .add() do?
'.add()' is used to add a value to set.

# What does .remove() do?
'.remove()' is used to remove a value from a set.

# Why is a set unordered?
A set is unordered because it stores items based on a hash function rather than a sequential index (like 0, 1, 2).

# When would you choose a tuple over a list?
A tuple is chosen over a list when the user doesn't want the values or objects to change.

# When would you choose a set over a list?
A set is chosen over a list when you want the valuse to be unique and want to eliminate repitition.

# What is a list?
A list in python is a variable that can contain more than one value or object, it is mutable, allows duplicates, indexable and ordered. 

# Why are lists useful?
Lists are useful because they are variables that can contain more than a single value.

# Why does Python start indexing at 0?
Python starts indexing at 0 because it uses zero-based indexing.

# What does append() do?
'append()' is used to mutate a list by adding an extra value to that list.

# What does remove() do?
'remove()' is used to mutate a list by taking out a value to that list.

# What does len() return?
The 'len()' function is used to check the number of objects in the list.

# What is the difference between fruits[0] and fruits[-1]?
'fruits[0]' stores the value of the first object in a list while 'fruits[-1]' reads the list from behind which stores the last value in the list.

# Why are lists called mutable?
Lists are called mutable because you can make change sto the list.

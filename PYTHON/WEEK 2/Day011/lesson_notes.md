# File handling
It is reading from to writing to file on your computer.

# open()
It is a built-in function that takes in argument which are text name and mode.

# Read mode
It allows a user read from a text file.

# Write mode
It allows a user write to a text file.

# Append mode
It allows a user add content to a text file.

# with
with automatically closes the file after the block of code finishes executing.

# .read()
The method used to read a text file.

# .write()
THe method used to write a text file.

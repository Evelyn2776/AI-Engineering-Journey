# Modules
MOdules are python file that can be reused in another python file.

# import
'import' is a keyword used to call a module into a python file.

# from ... import ...
'from...import...' is a short to import a module, instead of importing the entire python file (module) you can just import a particular function in the python file.

# Standard Library
The Python Standard Library is a collection of modules and packages included with Python that provide commonly needed functionality.

# random
It is a library that returns a random value in a  list or range of values.

# datetime
It is a library that returns the date and time of what you specify.

# Code reuse
Code reusability is the ablity to use a code in another python file.

# Modular programming
Modular programming is a software design technique that splits a large program into separate, independent sub-parts called modules.

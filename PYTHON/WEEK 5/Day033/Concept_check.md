# Day 033 - Concept Check
1. **What is a decorator?**
   A function that modifies or extends another function's behavior.

2. **What does `@decorator` do?**
   It applies the decorator to a function.

3. **What is a nested function?**
   A function defined inside another function.

4. **Why use `*args` and `**kwargs`?**
   They allow a decorator to handle different arguments.

5. **Can functions be passed as arguments?**
   Yes.

6. **Why are decorators useful in AI engineering?**
   For logging, timing, authentication, error handling, and API tracking.

### Key Takeaway
```text
Function → Wrapper → Modified behavior
```

# Day 024 - Lesson Notes

## Encapsulation
Encapsulation is the practice of keeping data and the methods that operate on that data together inside a class while controlling how the internal data is accessed.

## Public Attributes
Public attributes can be accessed directly from outside a class.

## Protected Attributes
A single underscore (`_attribute`) is a convention indicating that an attribute is intended for internal use.

## Private Attributes
A double underscore (`__attribute`) triggers name mangling and makes accidental access to an attribute more difficult.

## Attributes
Attributes are variables that store an object's data or state.

## Methods
Methods are functions defined inside a class that describe an object's behavior.

## Why Encapsulation Matters in AI Engineering
Encapsulation can help control access to sensitive or important application state such as conversation history, token usage, model configuration, and other internal data.

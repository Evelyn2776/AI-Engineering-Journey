# Day 045 — GitHub Collaboration

## Questions & Answers

**What is a fork?**
A personal GitHub copy of another repository, commonly used for open-source contributions.

**What does `git fetch` do?**
Downloads information about remote changes without automatically merging them.

**What does `git pull` do?**
Downloads and integrates remote changes into the current branch.

**What is the difference between fetch and pull?**
`fetch` gets the information; `pull` gets and integrates the changes.

**Why use Pull Requests?**
To review and safely merge changes into a project.

**What is the collaboration workflow?**
Clone → Branch → Code → Commit → Push → Pull Request → Review → Merge.

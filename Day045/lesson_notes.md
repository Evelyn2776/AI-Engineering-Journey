# Day 045 — GitHub Collaboration

## What I Learned
GitHub allows multiple developers to work on the same project using branches and Pull Requests.

I also learned the difference between `git fetch` and `git pull`.

### Important Commands
```bash
git fetch
```
Downloads information about remote changes without integrating them into the current branch.

```bash
git pull
```
Downloads remote changes and integrates them into the current branch.

```bash
git push
```
Sends local commits to GitHub.

## Collaboration Workflow
```text
Clone → Branch → Code → Commit → Push → Pull Request → Review → Merge
```

## Key Takeaway
Branches and Pull Requests allow developers to collaborate safely while keeping the main project stable.

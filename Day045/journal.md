# Day 045 — GitHub Collaboration

## Today I Learned
Today I learned how developers collaborate using GitHub, branches, and Pull Requests.

## Problem I Faced
Understanding the difference between `git fetch` and `git pull`.

## How I Solved It
I learned that `fetch` downloads remote information without integrating it, while `pull` downloads and integrates the changes.

## Reflection
I now understand the basic workflow developers use to collaborate on GitHub projects.

# Day 016 - Concept Check

## Question 1
### What is an API?
A software bridge that lets two applications talk to each other.

## Question 2
### What is an HTTP request?
A message sent from a client to a server asking for data.

## Question 3
### What does GET mean?
An HTTP method used specifically to retrieve or fetch data from a server.

## Question 4
### What is an API response?
The answer or data a server sends back after receiving a request.

## Question 5
### What does status code 200 mean?
A standard web code meaning the request was successful.

## Question 6
### What does response.json() do?
A Python method that converts raw API response data into a usable dictionary.

## Question 7
### Why are APIs important in AI Engineering?
They allow developers to easily connect their apps to powerful external AI models.

## Question 8
### Why should API requests have error handling?
It prevents your app from crashing if the network drops or the server fails.

## Question 9
### What is the relationship between APIs and JSON?
JSON is the standard format used by APIs to package and transport data.

## Question 10
### What happens when your Python program calls an API?
Your script pauses, sends a web request, waits, and receives data back.

# Day 043 — GitHub & Remote Repositories

## Questions & Answers

**What is a remote repository?**
A Git repository stored online, such as on GitHub.

**What is `origin`?**
The default name commonly given to the remote repository.

**What does `git push` do?**
Sends local commits to the remote repository.

**What does `git pull` do?**
Gets changes from the remote repository.

**What does `git clone` do?**
Creates a local copy of a remote repository.

**How do you view connected remotes?**
```bash
git remote -v
```

**What is the difference between Git and GitHub?**
Git manages version control, while GitHub hosts Git repositories online.

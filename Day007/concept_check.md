# What is a function?
Function in python is a named block of reusable code that performs a specific task.

# What is the difference between a parameter and an argument?
A parameter is inside a function's definition while an argument is the actual value passed into the function.

# What does return do?
Return sends back the value of what you want or what your function stands for when the fuction is called.

# What is the difference between printing a value and returning a value?
print() displays a value on the screen.
return sends a value back to the code that called the function, where it can be stored, printed, or used in further calculations.

# What is local scope?
A local varible is a variable that is created in a function, the varible can't be used outside that function and restricted to only the function.

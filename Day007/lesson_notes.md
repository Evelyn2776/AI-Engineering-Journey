# Functions
Functions are reusable blocks of code that carry out a specific task.

# def
def is a keyword used to define a function.

# Parameters
Parameters are used inside a functions definition.

# Arguments
Arguments are actual values or data that are passed into a function.

# return
return is a keyword used to pass a value as the result of running a function.

# Scope
scope of a variables is to tell if the variable is local or global.

# What is a Boolean?
Boolean is a data type in python which only has two values which are True (ON) and False(OFF).

# What does if do?
The if statement allows a program to make decisions based on a condition.

# What does else do?
The else statement is used at the end in a decision making, it is a fail safe. If the other decision where not met it just excute the else statement, so the else doesn't come with a condition.

# What does elif do?
The elif statement in python means (else if), when used it checks if the condition is true. If the condition is true, Python executes that block and skips the remaining elif and else blocks.

# Why is indentation important in Python?
Python uses indentation to define blocks of code. Without the correct indentation, Python raises an IndentationError. When writing a function or decision block you indent by 4 spaces to show that every other thing below is under that function.

# What is the difference between = and ==?
The = sign is used to assign a variable to a value while the == is used to compare two objects.

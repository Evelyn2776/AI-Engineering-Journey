# Day 044 — GitHub Branches & Pull Requests

## Questions & Answers

**What is a remote branch?**
A branch stored on the remote GitHub repository.

**How do you push a branch to GitHub?**
```bash
git push -u origin feature-name
```

**What is a Pull Request?**
A request to review and merge changes from one branch into another.

**Why use Pull Requests?**
They allow code to be reviewed and tested before being merged.

**How do you view remote branches?**
```bash
git branch -r
```

**What is the typical workflow?**
Create branch → code → commit → push → Pull Request → review → merge.

# Tuples
A collection of data which are immutable, ordered, indexed and allows duplicates.

# Immutable objects
Immutable objects that doesn't allow change to be made. e.g tuples.

# Sets 
A set is a collection of data that is mutable, unindexed, unordered and doesn't allow duplicates.

# Unique values
Unique values are values that a different in all ways and you can't the same of that value in the array and that what set does, by removing duplicates.

# .add()
'.add()' this function is used to add a value to a set.

# .remove()
'.remove()' this function is used to remove a value from a set.

# Differences between lists, tuples, and sets
LISTS: used when order matters, you want duplicates and want to modify the list.
TUPLES: used when you want data unchanged and want to protect important values.
SETS: used when you want values to be unique, don't want order and want to remove duplicates.

# What does input() do?
The pyhton built-in function 'input()' allow users to give an input or write your indiviual answer into the code.

# Why does input() always return a string?
When an input is recieved by python interpreter it takes it all as a string including numbers. That is because you are giving it pure human language, Python doesn't store input as strings because it "doesn't understand human language." It stores input as strings because everything typed at the keyboard arrives as text. Python cannot automatically know whether "23" is meant to be a number, an age, a ZIP code, or part of a phone number, so it safely treats it as text until you decide how to use it.

# What does int() do?
The 'int()' type converts an input or another data type to and integer (numbers).

# What does float() do?
The 'float()' type converts an input or another data type to and float (numbers with decimal points).

# What does str() do?
The 'str()' type converts an input or another data type to and string (words and letters).

# Why is data type conversion important?
Data converstion is important because without it all inputs will be seen as strings and will not be used in other formats like using numbers to do calculations.

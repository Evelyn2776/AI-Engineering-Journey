# What is file handling?
File handling is the process of reading from and writing to files on your computer.

# What does open() do?
'open()' is a python built-in function that is used to read or write a text file.

# What is the difference between "r", "w", and "a"?
The 'r' is uesd to read a text file file, the 'w' is used to write a text file and the 'a' is used to append a text file.

# Why is with open(...) recommended?
with open() is recommended because Python automatically closes the file when the block finishes, even if an error occurs.

# What happens if you open a file with "w" and it already exists?
It will over-write what was previously in the file.

# What does .read() do?
It is a python built-in function that allows you read from the file.

# What does .write() do?
It is a python built-in function that allows you write to the file.

# When would you use append mode?
The append is used when you want to add to the file content not change the file content.

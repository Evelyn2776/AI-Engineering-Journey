# Day 041 — Learning Journal

## Today I Learned
Today I learned the fundamentals of Git and how version control works. I learned the difference between Git and GitHub, as well as the purpose of repositories, the working directory, the staging area, and commits. I also practiced important commands such as:
```bash
git status
git add
git commit
git diff
git diff --cached
git log --oneline
```

## Problems I Faced
The main challenge was understanding the difference between the working directory, staging area, and committed changes.

## How I Solved It
I understood the process by thinking of Git as a checkpoint system:
```text
Working Directory
       ↓
    git add
       ↓
Staging Area
       ↓
  git commit
       ↓
Commit History
```

Git will be important throughout my AI Engineering journey because my AI projects, APIs, agents, RAG systems, and deployment projects will all need version control.

## Reflection
I now understand the basic Git workflow and why version control is essential for professional software development.

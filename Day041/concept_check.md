# Day 041 — Concept Check

### 1. What is Git?
Git is a version-control system for tracking changes in code.

### 2. What is GitHub?
GitHub is an online platform for hosting and collaborating on Git repositories.

### 3. What is a repository?
A repository is a project tracked by Git.

### 4. What does `git status` do?
It shows the current state of the working directory and staging area.

### 5. What does `git add` do?
It moves selected changes into the staging area.

### 6. What does `git commit` do?
It saves staged changes as a checkpoint in Git history.

### 7. What does `git diff` show?
It shows changes that have not been staged.

### 8. What does `git log --oneline` show?
It shows previous commits in a compact format.

### 9. What is the basic Git workflow?
```text
Edit → Status → Add → Commit
```

### 10. Why is Git important for AI engineering?
It helps manage code, track changes, collaborate, and maintain professional projects.

# Day 041 — Git Basics

## What I Learned

### Git
Git is a version-control system used to track changes in code over time.

### GitHub
GitHub is an online platform used to store, share, and collaborate on Git repositories.

### Repository
A repository is a project tracked by Git.

### Working Directory
The working directory contains the files I am currently working on.

### Staging Area
The staging area contains changes selected for the next commit.
```bash
git add Day041
```

### Commit
A commit is a saved checkpoint of the project.
```bash
git commit -m "Complete Day 041 - Git Basics"
```

## Important Commands
```bash
git status
git add
git commit
git diff
git diff --cached
git log --oneline
```

## Basic Git Workflow
```text
Edit files
    ↓
git status
    ↓
git add
    ↓
Staging Area
    ↓
git commit
    ↓
Saved Checkpoint
```

## Why Git Matters in AI Engineering
Git allows AI engineers to:
* Track code changes
* Restore previous versions
* Collaborate with other developers
* Manage projects safely
* Contribute to open-source projects
* Maintain professional GitHub repositories

## Key Takeaway
Git tracks my project's history and allows me to save changes as organized checkpoints.

# Class
'class' can be said to be a blueprint as it is reusable and allows other functions to be createed within it.

# Object
An object is an instance of a class. It contains its own data (attributes) and can perform actions through methods.

# __init__()
The '__init__()' is used to initalize a new object in a class.

# self
'self' is a particular object currently being created or used.

# Attribute
An attribute is a variable that belongs to an object and stores information about that object.

# Method
Method is another word for behavior in used in Object Oriented Programming.

# Why OOP is useful
(OOP) Object Oriented Programming is a way of organizing programs around an object.

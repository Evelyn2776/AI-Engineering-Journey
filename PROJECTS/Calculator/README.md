# Calculator

A command-line calculator built with Python as part of my AI Engineering learning journey.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Power
* Continuous calculations
* Input validation
* Division-by-zero handling
* Automated testing

## Project Structure
```text
Project-01-Calculator/
├── calculator.py
├── main.py
├── test_calculator.py
└── README.md
```
* `calculator.py` — Contains the `Calculator` class and mathematical operations.
* `main.py` — Handles the CLI menu, user input, and application flow.
* `test_calculator.py` — Contains automated tests.
* `README.md` — Project documentation.

## Requirements
* Python 3.12+
* pytest

## Usage
Run the calculator:
```bash
python main.py
```
Choose an operation from the menu and enter the required numbers. To run the tests:

```bash
pytest
```

## Error Handling
The calculator handles:
* Invalid number input
* Invalid operations
* Division by zero

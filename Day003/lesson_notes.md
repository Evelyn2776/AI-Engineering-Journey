# What is Memory?
RAM is temporary memory that stores data and objects while a program is running.

# What is an object?
An object in python is anything you write or create, every information is an object (numbers, words, letters, signs and everything else).

# What is a variable?
A variable is not really a container for values, it is more like a pointer that refers to the value or object created.

# Difference between = and ==
The '=' sign is used to assign a variable to a value, while the '==' is used to compare a variable and value or object.

# type()
This is a python built-in function that is used to check the data type of an object.

# id()
This is a python built-in function that is used to return the identity of an object during a python session. It distinguish one object from another.

# Basic data type
Python has 4 basic data types which are:
Integer (int)
Float (float)
String (str)
Boolean (bool)

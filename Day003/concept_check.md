# What is memory?
Memory (RAM) is temporary storage where Python keeps objects and data while a program is running.

# What is an object?
An object is a piece of data created by Python, such as a number, string, list, or Boolean, that exists in memory.

# What is a variable?
A variable in python is a pointer to an object created  which can be a string, integer etc.

# What is the difference between = and ==?
The = is used to assign while == is used to compare.

# What does type() do?
It shows you the data type of the object

# What does id() do?
It distinguishes one object from another during a Python session.

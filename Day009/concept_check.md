# What is a dictionary?
A dictionary is a collection of data that has 2 sections a key and a value which are mapped for better clarification.

# What is a key?
A key is a data in a dictionary that explains what the value stands for.

# What is a value?
A value is a data that carries the information the user needs.

# How is a dictionary different from a list?
A dictionary doesn't just carry a collection of values like a list, a dictionary carries keys and values which the key acts as a pointer to the value and the value holds the information needed.

# How do you add a new key-value pair?
A new key-value is added by calling the dictionary name, in a square bracket the key equal to the value. E.g student["age"] = 23.

# How do you update a value?
Updating a list is done the same way like adding a key-value, now that we have age in our dictionary called student lets update age. E.g student["age"] = 24, now age is 24 and not 23.

# What does .items() do?
The .items() method is a built-in Python dictionary function that returns a view object containing the key-value pairs of the dictionary as tuples.

# When would you choose a dictionary over a list?
A dictionary is used instead of a list when the information doesn't just contain values but it contains both key and value.

# Dictionaries
A collection of data which contains both keys and values.

# Keys
Keys are information that explains the purpose of the value and it's written before the value.

# Values
Values are the information the user needs and they are written after the key and a colon(:).

# Adding items
Adding a new key-value to a dictionary, student["age"]=23.

# Updating items
Updating items is changing the current value in a dictionary key from one object to another, student["age"]=24.

# Removing items
Removing items from a dictionary, del student["age"].

# Looping with .items()
.items() allows you to loop through both the keys and values and map each key to a value and present it as one data.

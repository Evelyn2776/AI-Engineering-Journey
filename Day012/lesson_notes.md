# Exceptions
Runtime error events that disrupt normal program execution.

# try
Defines a monitored code block to test for potential runtime errors.

# except
Catches and handles specific errors raised within the try block.

# ValueError
Raised when an argument has the right type but an invalid value.

# ZeroDivisionError
Raised when dividing a number or calculating modulo by zero.

# else
Executes an isolated code block only if no exceptions occurred.

# finally
Executes code no matter what, ensuring resource cleanup.
